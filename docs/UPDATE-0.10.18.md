# SkyDek DJ 0.10.18

This signed Windows update contains the latest beta-tested SkyDek DJ workspace and Mix Editor improvements.

## Controller and library usability

- Double-click a library track to load it into a safe available DEK.
- Empty DEKs are preferred; stopped DEKs may be reused; playing DEKs are protected.
- The virtual Xbox controller shows the active Normal or Shift assignment beside each control.
- Mapping labels follow saved and custom mapping profiles and update while editing.

## Updating

Existing signed Windows installations can use **Check for updates**. The application downloads and verifies the signed NSIS updater from the latest GitHub release before installation.

The Windows update is published through the project release workflow. macOS packaging remains a separate manually triggered workflow.

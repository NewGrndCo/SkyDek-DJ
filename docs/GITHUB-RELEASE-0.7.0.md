## SkyDek DJ 0.7.0 — Refined Windows workspace

The same standalone Xbox-controlled DJ application, with a cleaner presentation:

- Matte graphite panels and restrained purple accents.
- Clearer typography, spacing, library rows, and folder location labels.
- Compact effect groups, aligned transport controls, and three hot cues per deck.
- A collapsible controller guide and matching settings/sampler styling.
- Existing controller mappings, sampler modes, library, and preferences carry forward.

### Download and update

**SkyDek-DJ-0.7.0-Windows.zip** includes the installer, user guide, and third-party notices. Choose **SkyDek-DJ-0.7.0-Windows-Setup.exe** for the installer alone.

Extract the ZIP, stop recording, and exit the older SkyDek instance from its system-tray menu before running setup. Opening the new installer updates the installed application. Your existing library and settings use the same storage location.

Microsoft WebView2 is downloaded during setup if missing. loopMIDI and VirtualDJ are not required. Use your own WAV/MP3 music and samples.

### Preview status

This remains a preview. Automatic BPM analysis, phase sync, stems separation, and separate headphone cueing are unavailable. Tempo changes also affect pitch. The installer is unsigned. Test your audio output and controller before live use.

Production build and 33 regression tests passed. Native visual review covered empty/loaded decks and General settings at the development display size. Broader display and extended hardware testing remain unverified.
